# 畜牧兽医管理分系统演示 Demo 产品需求文档

## 1. 产品概述

畜牧兽医管理分系统演示 Demo 面向养殖场户、官方兽医、屠宰企业和监管人员，重点展示“产地检疫—运输监管—屠宰入场—屠宰检疫—产品出证”的数据流转闭环。

系统不接入真实后端，通过前端 mockApi、Pinia 和 localStorage 模拟完整业务流程，帮助演示动物检疫监管数字化、无纸化出证、异常预警和全链路追溯能力。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 养殖场户 | 登录页选择角色进入 | 提交产地检疫申报、查看申报详情、查看电子检疫证明 |
| 官方兽医 | 登录页选择角色进入 | 审核产地检疫申报、模拟现场查验、无纸化出证、审核屠宰检疫 |
| 屠宰企业 | 登录页选择角色进入 | 入场查验、提交非瘟检测和违禁药物自检结果、提交屠宰检疫申报 |
| 监管人员 | 登录页选择角色进入 | 查看调运监管一张图、查看检疫屠宰监管看板、查看预警和操作日志 |

### 2.2 功能模块

1. **登录/角色选择页**：展示四类业务角色入口，进入后根据角色跳转到对应工作台。
2. **养殖场户端：产地检疫申报页面**：选择养殖批次、动物种类、数量、车辆、承运人、目的屠宰场并提交申报。
3. **养殖场户端：申报详情与电子检疫证明页面**：查看申报状态、校验结果、检疫证明、运输任务和业务时间线。
4. **官方兽医端：产地检疫待办页面**：查看待审核申报，按状态筛选并进入现场查验。
5. **官方兽医端：现场查验与无纸化出证页面**：模拟人脸识别、现场查验、拍照取证，生成动物检疫合格证明。
6. **监管端：调运监管一张图页面**：展示运输任务、车辆轨迹、异常预警、调运状态。
7. **屠宰企业端：入场查验页面**：通过车牌或证明编号核验检疫证明、车辆、耳标、数量、轨迹、黑名单和指定通道。
8. **屠宰企业端：屠宰检疫申报页面**：提交非瘟检测、违禁药物自检、待宰数量和申报材料。
9. **官方兽医端：屠宰检疫审核与产品出证页面**：完成宰前检查、宰后检疫、产品出证。
10. **监管端：检疫屠宰监管看板页面**：展示从养殖场到屠宰场的完整链路、关键指标、预警记录和操作日志。

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录/角色选择页 | 角色入口 | 使用四张角色卡片进入对应端，展示闭环流程概览 |
| 产地检疫申报页面 | 自动校验 | 提交前校验存栏、耳标、免疫、车辆、承运人；异常时写入预警 |
| 申报详情与电子检疫证明页面 | 电子证明 | 展示证明编号、动物信息、起运地、目的地、承运信息、二维码模拟区域 |
| 产地检疫待办页面 | 待办列表 | 展示申报编号、养殖场、动物种类、数量、提交时间和状态 |
| 现场查验与无纸化出证页面 | 查验表单 | 模拟人脸识别、现场查验、拍照取证，审批通过后出证并扣减存栏 |
| 调运监管一张图页面 | 轨迹监管 | 展示车辆路线、节点、轨迹状态、异常预警和运输任务详情 |
| 入场查验页面 | 自动核验 | 输入车牌或证明编号，系统核验证明、数量、耳标、轨迹、黑名单和指定通道 |
| 屠宰检疫申报页面 | 企业自检 | 提交非瘟检测结果、违禁药物自检结果和待宰批次信息 |
| 屠宰检疫审核与产品出证页面 | 产品出证 | 官方兽医完成宰前和宰后检查，生成产品检疫合格证明 |
| 检疫屠宰监管看板页面 | 全链路看板 | 展示全链路状态、关键指标、预警、日志、证明与产品流向 |

## 3. 核心流程

养殖场户提交产地检疫申报后，系统通过 mockApi 自动校验存栏、耳标、免疫、车辆和承运人。官方兽医在待办中审核申报，完成模拟人脸识别、现场查验和拍照取证后生成动物检疫合格证明。出证后系统扣减养殖批次存栏，并生成运输任务。监管人员在一张图中查看运输轨迹和异常预警。屠宰企业入场时通过车牌或证明编号核验证明与运输信息，入场通过后提交屠宰检疫申报。官方兽医完成屠宰检疫审核并生成产品检疫合格证明。监管看板展示完整闭环链路。

```mermaid
flowchart TD
  A["养殖场户提交产地检疫申报"] --> B["系统自动校验存栏耳标免疫车辆承运人"]
  B --> C{ "校验是否通过" }
  C -->|"通过"| D["官方兽医待办审核"]
  C -->|"异常"| E["生成预警记录并提示修改"]
  D --> F["现场查验与无纸化出证"]
  F --> G["扣减存栏并生成运输任务"]
  G --> H["监管端查看运输轨迹和异常预警"]
  H --> I["屠宰企业入场查验"]
  I --> J{ "入场核验是否通过" }
  J -->|"通过"| K["提交屠宰检疫申报"]
  J -->|"不通过"| L["生成入场异常预警"]
  K --> M["官方兽医屠宰检疫审核"]
  M --> N["生成产品检疫合格证明"]
  N --> O["监管看板展示全链路闭环"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深墨绿、监管蓝、琥珀橙，用于体现农业监管、风险预警和数据化业务流。
- 辅色：浅绿、雾白、石板灰，用于卡片、分割线和数据背景。
- 按钮：Element Plus 圆角按钮，主要业务操作使用绿色，风险操作使用橙色或红色。
- 字体：优先使用系统中文字体，标题使用较粗字重，数据指标使用等宽风格数字。
- 布局：桌面优先，左侧业务导航 + 顶部角色信息 + 内容区卡片和监管看板布局。
- 图形：使用状态徽标、时间线、步骤条、模拟地图轨迹、二维码占位和指标卡。

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录/角色选择页 | 角色卡片 | 深色渐变背景、四张入口卡片、流程链路装饰 |
| 产地检疫申报页面 | 申报表单 | 分组表单、校验结果面板、批次库存卡片 |
| 申报详情与电子检疫证明页面 | 证明详情 | 证明卡片、二维码模拟、状态时间线、运输信息 |
| 产地检疫待办页面 | 待办列表 | 筛选标签、数据表格、状态标签、快速操作按钮 |
| 现场查验与无纸化出证页面 | 查验工作台 | 查验步骤、模拟识别结果、取证图片占位、出证按钮 |
| 调运监管一张图页面 | 监管地图 | 模拟路线、车辆点位、风险浮层、任务列表 |
| 入场查验页面 | 核验面板 | 搜索框、核验清单、通过/驳回操作、异常提示 |
| 屠宰检疫申报页面 | 自检申报 | 检测结果表单、入场批次信息、材料提交状态 |
| 屠宰检疫审核与产品出证页面 | 审核出证 | 宰前宰后检查表、产品证明卡片、审核操作 |
| 检疫屠宰监管看板页面 | 监管大屏 | KPI 指标、全链路步骤、预警列表、操作日志 |

### 4.3 响应式设计

采用桌面优先设计，主要适配 1366px 以上演示屏幕。窄屏下侧边栏折叠为顶部导航，表格和看板卡片采用单列堆叠展示。表单控件保持触控友好的高度和间距。
